# მათბოტი — ტექნიკური აღწერა

მეშვიდე კლასის მათემატიკის სახელმძღვანელოს RAG-ასისტენტი.
მომხმარებლისთვის განკუთვნილი ინსტრუქცია: `წამიკითხე.md`

## არქიტექტურა

```
შეკითხვა → TF-IDF მოძიება (47 სექცია) → ტოპ-3 სექცია
         → Claude API (სისტემური ინსტრუქცია + სარჩევი + კონტექსტი)
         → პასუხი + წიგნის მითითება
```

მოძიება იყენებს სიმბოლოთა n-გრამებს (`char_wb`, 3-5), რაც ქართული
ბრუნვების მიმართ მდგრადია — სიტყვებზე დაფუძნებული ძიება
„მოდულის" და „მოდული"-ს ვერ აკავშირებს.

## ფაილები

| ფაილი | დანიშნულება |
|---|---|
| `app.py` | Streamlit აპლიკაცია |
| `theme.py` | მასკოტის SVG და CSS |
| `assets/*.png` | მასკოტის ავატარები ჩატისთვის |
| `system_prompt.md` | პედაგოგიური და უსაფრთხოების წესები |
| `build_kb.py` | PDF → `data/chunks.json` |
| `data/chunks.json` | 47 სექცია, გვერდების მიბმით |

## ცოდნის ბაზის ხელახლა აწყობა

```bash
# საჭიროა data/math7.pdf
python3 build_kb.py
```

სარჩევი `build_kb.py`-ში ხელითაა გაწერილი (`TOC` სია), რადგან
PDF-ს bookmark-ები არ აქვს. სხვა სახელმძღვანელოზე გადასატანად
სწორედ ეს სია უნდა შეიცვალოს.

## პარამეტრები

`app.py`-ის თავში:
- `MODEL` — მოდელი
- `TOP_K` — რამდენი სექცია მიეწოდოს კონტექსტში (ნაგულისხმევი 3)
- `HISTORY_TURNS` — საუბრის სიღრმე

## ცნობილი შეზღუდვები

- ნახაზები და ილუსტრაციები არ გადმოდის (მხოლოდ ტექსტური შრე)
- ვარსკვლავები სესიაშია, ბაზაში არ ინახება
- ავტორიზაცია არ არის — მხოლოდ ლოკალური გამოყენებისთვის
